# Mod `cuota` — plan de implementación

> Ejecución inline en la sesión que escribió el plan (un solo módulo muy acoplado; no se reparte en subagentes). Pasos con checkbox.

**Objetivo:** un mod de Claude Code que muestra siempre, arriba del prompt, el modelo, el contexto y las ventanas de 5 h y 7 d del plan, y que avisa y ofrece la acción sólo cuando algo cruza un umbral.

**Arquitectura:** un módulo de hooks (`hooks/register.tsx`) que lee las cifras que el motor empuja (`session.measure`, `$.session.usage()`), las guarda en `$.state` y las dibuja en la banda (`AbovePrompt`) y en un panel (`/cuota`). Toda la aritmética y el formato viven en `hooks/math.ts`, puro y testeado aparte. El historial semanal va en `$.store`, compartido entre sesiones.

**Stack:** API de mods de Claude Code 2.1.292 (early access), TypeScript/TSX, `claude plugin validate`, `claude plugin test`.

Propuesta y mock: https://claude.ai/artifact/DC1rsAQxY1euSxt4nnYfhu

## Reglas de severidad

- **Contexto:** `ok` < 70 %, `warn` 70–89 %, `crit` ≥ 90 % (configurable).
- **Ventanas** (`five_hour` = 5 h, `seven_day` = 7 d): `elapsed = 1 − left/T`, `pace = used / elapsed`, `eta = (100 − used) / (used / (T − left))`.
  - `pace > 1` equivale exactamente a «llega al 100 % antes del reset» (`eta < left`).
  - La proyección es confiable cuando `elapsed ≥ 0,2` o `used ≥ 40`.
  - `crit`: `used ≥ piso` (80 % en 5 h, 90 % en 7 d), o proyección confiable con `pace > 1` y `used ≥ 50`.
  - `warn`: proyección confiable con `pace > 1`.
  - Una ventana sin largo conocido (`spend_limit`) sólo usa el piso.
